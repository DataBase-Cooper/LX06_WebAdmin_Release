## 小智

文件 `xz_watch.sh`。支持本地唤醒绑定、官方唤醒绑定和小爱通道词。使用前打开扩展「检查绑定」，按页面提示在小智控制台完成配对。已绑定通常会进入「对话设置」。

| 设置 / 字段名 | 用法 |
| --- | --- |
| 打断方式 `XZ_BARGE_ANY` | 默认打断词。切换到人声会立即显示人声门槛，保存后下次对话生效。 |
| 打断音量门槛 `XZ_BARGE_RMS` | 只在人声模式生效。范围 400–8000，默认 1400，越高越需要大声说话。 |
| 打断词 `XZ_INTERRUPT_TEXT` | 小智正在说话时，说配置的词中断当前播报，接着可以提出新问题。 |
| 结束词 `XZ_GOODBYE_TEXT` | 用于结束整段小智对话。可以设置多个词。 |
| 小爱通道词 `official_wake` | 官方小爱先启动，再用这个词切换到小智。留空关闭该入口。 |
| 预留换气时间 `XZ_LISTEN_PAUSE_MS` | 默认关闭。可选 1、1.5、2、3、4、5、8 秒，用于长句中间停顿。停顿超过设定时间后提交本轮语音。 |
| 换气结束词 `XZ_LISTEN_END_WORD` | 开启预留换气后才显示，默认「发送」。说完正文短停，再单独说结束词可提前提交。结束词音频不会交给小智。留空关闭提前提交。 |
| 智能家居控制 `XZ_HOME_MCP` | 默认关闭。开启后显示已上传的智能家居接入脚本。 |
| 智能家居 MCP 脚本 `XZ_HOME_MCP_SCRIPT` | 使用米家时选 `mijia_mcp.sh`。需要先上传该脚本，保存后下一次对话生效。 |
| 声音增益 `XZ_INPUT_GAIN_DB` | 调整正常收音上行的增益，范围 −12 至 +12 dB，0 表示原增益。这个设置适合调清收音，不能代替设备输出音量。 |
| 连接令牌 `XZ_ACCESS_TOKEN` | 可填写手动令牌。已经正常配对的设备通常使用现有绑定。留空保存时保留已存令牌。 |
| 无交互退出 `XZ_IDLE_TIMEOUT_MS` | 普通对话多久没有交互后退出，单位毫秒。0 禁用该空闲退出条件。 |
| 长任务连接保留 `XZ_KEEPALIVE_MINUTES` | 可提高本机对长会话的保留时长，单位分钟，0 关闭。只用 MCP 自动查询通常保持 0 即可。小智服务器仍可能主动结束会话。 |
| MCP 自动查询 `XZ_MCP_TASK_AUTO` | 默认开启。支持登记的网关可在同一会话安排最多 8 个后台任务，按任务自己的查询指令取进度和结果。 |
| 备用查询指令 `XZ_MCP_TASK_QUERY` | 正常留空。供旧网关没有随任务提供查询指令时使用。支持用 `{id}` 插入任务编号。 |
| 最长会话 `XZ_MAX_SESSION_SECONDS` | 单次对话的本机会话上限，单位秒。与服务器侧限制共同决定实际连接时长。 |
| 播放回复 `XZ_PLAYBACK` | 控制本地是否播放服务回复音频，用于普通使用或排查播放故障。 |
| 连接超时 `XZ_CONNECT_TIMEOUT_MS` | 等待小智连接的上限，单位毫秒。用于网络或配对后连接慢的排查。 |
| 等待麦克风 `XZ_MIC_WAIT_MS` | 会话启动时等待受管麦克风流的上限，单位毫秒。 |
| 尾音保护 `XZ_PLAYBACK_TAIL_MUTE_MS` | 播报结束后短暂保护上行收音，减少尾音回灌。调得越长，重新收音可能越晚。 |
| 结束词后等待回复 `XZ_GOODBYE_WAIT_MS` | 识别结束词后，允许服务开始回复的等待时间。 |
| 结束回复关闭期限 `XZ_GOODBYE_CLOSE_MS` | 给结束回复留出的关闭期限，用于回收结束中的连接。 |
| 退出播放收尾 `XZ_PLAYBACK_DRAIN_MS` | 正常退出时给排队音频的收尾时间。仅用于高级播放排查。 |

页面操作有「读取当前配置」`load`、「保存配置」`save` 和「检查绑定」`bind`。「检查绑定」负责读取配对状态和显示配对指引。任务进度随网关上报更新，用户说再见后结束本轮自动查询。[小智 MCP 接入](../kws/lx06-installer/docs/xiaozhi-mcp-task-polling.md)

## 米家 MCP

文件 `mijia_mcp.sh`。上传后由小智的「智能家居控制」引用。原厂小爱在本机复用已有登录。无需再次填写账号，也无需逐台添加设备。当前支持开关设备、设置亮度、空调温度和运行模式，具体动作由原厂小爱按现有权限执行。

用语音控制时可以说「关闭客厅窗帘」。明确的开关指令会交给所选脚本，跨语音与云端工具的相同请求会去重。国内米家家庭中的同名设备可在指令中加房间名。返回「已受理」表示原厂服务已收到请求。[完整使用与脚本接口](../kws/lx06-installer/docs/xiaozhi-home-mcp.md)

## 豆包

文件 `doubao_watch.sh`。在「连接豆包」输入自己的 API Key，点击「验证连接」；验证连接后，到「对话设置」保存需要的交互参数。可通过本地唤醒、官方唤醒绑定或小爱通道词启动。

| 设置 / 字段名 | 用法 |
| --- | --- |
| 打断方式 `DB_BARGE_ANY` | rc42 新安装默认「打断词」。可切换到「人声」，两个分支的字段会立即切换显示。 |
| 打断词 `DB_INTERRUPT` | 仅打断词模式显示。说配置好的词才触发这个打断入口。 |
| 打断音量门槛 `DB_BARGE_RMS` | 仅人声模式显示。提高门槛后需要更强的人声，适合按出声距离和周围声音调整。 |
| 回声保护 `DB_ECHO_PROTECTION` | 仅人声模式显示。增强模式对持续人声的要求更高，用于降低播放回声触发的概率。 |
| 结束词 `DB_GOODBYE` | 结束与豆包的对话，可配置多个。 |
| 小爱通道词 `official_wake` | 说「小爱同学」后用保存的口令切到豆包。留空关闭。 |
| 唤醒后问候语 `DB_GREETING` | 配置唤醒时的问候内容。需要通过语音确认启动时可填写。 |
| 豆包 API Key `DB_API_KEY` | 连接服务的凭据。验证失败时排查服务权限、账户状态和网络。以后留空保存可保留旧值。 |
| 豆包连接地址 `DB_ENDPOINT` | 服务 WebSocket 地址。使用默认服务时保留默认值。 |
| 豆包音色 ID `DB_VOICE` | 请求回复时使用的音色。可用的值取决于服务支持。 |
| 角色与回复要求 `DB_INSTRUCTIONS` | 给豆包会话提供角色、风格和回复要求。 |
| 无交互退出 `DB_IDLE_SECONDS` | 多久没有交互后退出，单位秒。 |
| 最长会话 `DB_MAX_SECONDS` | 音箱允许单次豆包会话的最大时间。 |
| 播放回复 `DB_PLAYBACK` | 是否在音箱播放回复音频。 |
| 回复音频格式 `DB_AUDIO_FORMAT` | 选择 Opus 或 PCM。保持推荐值即可开始使用。 |
| 起播缓冲 `DB_PLAYBACK_BUFFER_MS` | 播放开头积累多少音频。提高缓冲有助于应对抖动，也会推迟起播。 |
| 识别调试 `DB_TRACE_ASR` | 排查识别问题时记录识别文本。平时可关闭，日志中可能包含说话内容。 |

页面操作有「读取当前配置」`load`、「保存设置」`save` 和「验证连接」`verify-key`。验证连接和保存对话设置是不同操作。切换打断方式后需要保存，后续会话才按新配置运行。

## ChatGPT

文件 `chatgpt_account.sh`。进入「登录账户」并按官网提示授权，将浏览器完整跳转地址填到「授权回调地址」`auth_callback`，再点「完成登录」。成功后进入「对话设置」。

- **对话模型 `model`。** 选择登录账户可用的模型。下拉列表不全时使用「更新模型列表」。
- **测试问题 `question`。** 在扩展提交一条文字请求，便于在绑定唤醒之前验证账户和模型。
- **语音与会话。** 使用下方的账户脚本共用设置。ChatGPT 的「播报节奏」用于调节流式回复的分句播放。

| 页面操作 | 行为 |
| --- | --- |
| 登录账户 `login` | 开始官网授权并给出下一步指引。 |
| 完成登录 `complete-login` | 使用刚刚取得的授权回调地址完成本地登录。 |
| 账户状态 `status` | 检查本地授权情况。 |
| 更新模型列表 `models` | 重新获取可选会话模型。 |
| 文字测试 `test` | 用预先选定的模型向服务发送测试内容。 |
| 退出本地账户 `logout` | 清理此音箱上该脚本的本地登录状态。 |
| 读取当前配置 `load` / 保存配置 `save` | 回读或更新本机脚本设置。 |

## DeepSeek

文件 `deepseek_account.sh`。按自己的 DeepSeek 账户登录方式选择短信验证码或密码。扩展可先检查登录并做文字测试，再通过唤醒词或通道词开始语音对话。

| 设置 / 字段名 | 用法 |
| --- | --- |
| 邮箱或手机号 `account` | 填用于登录的 DeepSeek 账户。 |
| 短信验证码 `sms_code` | 手机号验证码登录时填写收到的 6 位代码。 |
| 登录密码 `password` | 密码登录时填写自己的密码。 |
| 手机国际区号 `area_code` | 手机号登录使用。邮箱登录忽略该项。 |
| 测试问题 `question` | 输入一条文字问题，验证当前账户可以正常收到服务回复。 |
| 模型 `MODEL_ID` | 页面说明为 DeepSeek 官网自动匹配，按官网会话能力使用。 |
| 深度推理 `DS_THINKING` | 启用后请求深度推理，通常需等待更久。 |

页面操作包括「发送验证码」`send_sms`、「验证码登录」`sms_login`、「密码登录」`login`、「检查登录」`status`、「文字测试」`test`、「打开官网」`website`、「退出本地账户」`logout`、「读取状态」`load`、「保存对话设置」`save`。语音模式与问候、结束、超时配置见下文共用设置。DeepSeek 没有单独的播报节奏项。

## Grok

文件 `grok_account.sh`。点「登录账户」，在「官网授权」步骤按指引授权。成功后进入「对话设置」。

- **对话模型 `model`。** 选择 Grok 账户可用的模型。账户切换或列表更新后可点击「更新模型列表」。
- **测试问题 `question`。** 发起文字请求，确认已登录的模型可以出结果。
- **语音与会话。** 通过本地唤醒或小爱通道词启动。问候、打断、结束和播报节奏见共用设置。

页面操作包括「登录账户」`login`、「账户状态」`status`、「更新模型列表」`models`、「文字测试」`test`、「退出本地账户」`logout`、「读取当前配置」`load`、「保存配置」`save`。先验证文字再测试真实语音，有助于区分授权问题和音箱音频问题。

## 账户脚本共用设置

ChatGPT、DeepSeek、Grok 的这些字段含义一致，默认通道词和问候内容随脚本配置而定。

| 设置 / 字段名 | 用法 |
| --- | --- |
| 小爱通道词 `official_wake` | 先唤醒官方小爱，再用配置的口令启动对应账户脚本。多个词用逗号分隔，留空关闭。 |
| 打断词 `MODEL_INTERRUPT` | 播报过程中说该词，停止当前回复并继续对话。 |
| 结束词 `MODEL_GOODBYE` | 主动结束这一次语音会话。 |
| 唤醒后问候语 `MODEL_GREETING` | 设置启动时播报的文字。Web88 会为符合声明的脚本提供问候音频生成入口。 |
| 无交互退出 `MODEL_IDLE_SECONDS` | 无交互多久后回收会话，单位秒。 |
| 最长会话 `MODEL_MAX_SECONDS` | 单次会话的本地上限，单位秒。 |
| 语音响应优化 `MODEL_TTS_YIELD` | 控制脚本语音响应的高级优化开关。按会话时延和播报表现比较前后效果。 |
| 播报节奏 `MODEL_SPEECH_FLOW` | 仅 ChatGPT 和 Grok 含此项。改变流式文本转语音分句的节奏。 |
| 识别调试 `MODEL_TRACE_ASR` | 打开后记录识别的文本，用于排查听错内容或打断词。 |

这三个账户脚本还声明供设备内部接入使用的结构化入口，普通语音用户无需填写。

| 接口项 | 作用 |
| --- | --- |
| `request`、`prompt` | 结构化请求参数和传给模型整理的提示内容。由调用方按协议提交。 |
| `response` | 供调用方接收经过校验的结构化结果。 |
| `invocation` | 与本次受管调用关联的字段。由调用路径提供和校验。 |
| `status` | 连接状态字段，结构化调用前可检查账户能否使用。 |
| `extract` / `understand` | 供结构化提取和理解流程调用的两个动作。选择具体账户脚本后遵循相同的输入输出声明。 |

## 开门

文件 `open-door.sh`。通过支持的门禁服务执行一次动作。发布脚本的 Web88 扩展提供三个用户设置。脚本中的服务设备参数需对应自己的授权门禁，适配其他服务时要按该服务的接口调整实现。

| 设置 / 字段名 | 用法 |
| --- | --- |
| 手机号 `phone` | 填与门禁服务账户关联的号码。 |
| 密码 `password` | 填用户原始登录密码。脚本按服务要求处理登录。 |
| 小爱通道词 `official_command` | 默认「打开玻璃门」和「打开小区门」。保存后说「小爱同学」，再说其中一个词触发。留空关闭。 |

「读取配置」`load` 和「保存」`save` 用于读写扩展设置。真实动作从通道词进入 `--official-command`，执行结果由官方小爱播报。

## 独立 MCP

文件 `mcp_task_watch.sh`。从官方小爱通道词启动一次工具调用，任务完成后由同一发起设备回执。适合工单、服务状态等需要等待结果的工具。原小爱对话可以先结束。

| 设置 / 字段名 | 用法 |
| --- | --- |
| 小爱通道词 `official_command` | 触发独立 MCP 的口令。可改为你自己的任务名，留空关闭。 |
| MCP 服务地址 `endpoint` | 填 Streamable HTTP 入口，正常使用 HTTPS。音箱本机回环转发可使用 `http://127.0.0.1`。 |
| 访问令牌 `token` | 仅在网关需要认证时填写。 |
| 工具名称 `tool` | 填网关定义的准确工具名，例如 `get_work_order`。 |
| 工具参数 `arguments` | 传给工具的 JSON 对象，例如 `{"id":"order_132"}`。工具不需要参数时用 `{}`。 |
| 最长执行时间 `timeout` | 等待工具返回最终可播报内容的最长时间。范围 10 至 600 秒。 |

使用「读取配置」`load`、「保存」`save` 管理上述参数。每台音箱同时运行一个此类独立任务。若远端工具只返回任务编号，接入方需要提供一个能最终返回文本的封装工具。会话内的多任务进度播报使用小智的另一条接入路径。[两个 MCP 路径和接入方法](../kws/lx06-installer/docs/xiaozhi-mcp-task-polling.md)
