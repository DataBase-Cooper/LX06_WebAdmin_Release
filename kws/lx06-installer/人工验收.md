# LX06 V20261127.7-rc44 验收说明

本版增强镜像基于 V20261127.5-rc42。升级窗口在安装应答丢失时继续核对设备状态，重新启动后以实际版本与启动槽为准。报错可在升级窗口内复制。

刷机工具完整解压后运行 LX06Installer.exe。在线升级使用 .lx06ota 文件。保留 DATA 可保留现有账号、录音与脚本设置。执行清空 DATA 前请先备份。

八个脚本单独上传。小智可以在扩展内开启智能家居控制，选择已上传的 mijia_mcp.sh 使用音箱现有的小爱登录。新版小智和米家脚本已在 RC42 真机验证部署、保存与读取。用户确认客厅窗帘可关闭，空调模式切换、关机和回复均正常。多家庭归属、RC44 整机刷写与物理 USB 驱动安装待验收。
