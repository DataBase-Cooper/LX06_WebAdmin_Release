第 1 步 · Amlogic USB 驱动

刷机使用 Amlogic Flash Tool 的 WorldCup（libusb）驱动。驱动未就绪时，选择刷机包按钮会保持禁用。

普通方式打开本软件即可。点击“安装驱动”后，在 Windows 管理员授权弹窗中选择“是”；标准用户需要管理员账号。没有看到弹窗时，请检查任务栏；远程桌面用户请同时检查本机屏幕。

驱动签名安装帮助

遇到驱动签名错误或设备代码 52 时，先保存电脑上的工作。打开 Windows 恢复设置，在「高级启动」中选「立即重新启动」。

依次选「疑难解答 → 高级选项 → 启动设置 → 重启」，再按 7 或 F7。进入 Windows 后重新打开本工具，点击「安装驱动」。这次选择只在本次启动有效。

开始刷写 · 官方固件 + SSH

将覆盖 system0 分区。是否在写入前清空 DATA 分区（用户数据/网络配置），请勾选下方选项。确认后软件会提示您接好 USB 数据线，并给小爱断电后重新上电（重新供电一次）进入刷机模式。SSH 配置会烘焙进固件，开机即生效。

SSH 端口89（仅局域网）
SSH 密码DB_COOPER
HTTP 控制台http://<音箱IP>:88（同密码）

无需填写任何配置，直接点「确认开始刷机」即可。刷完后浏览器登录上方 HTTP 控制台（默认密码 DB_COOPER）可自行修改密码、上传部署脚本、重启小爱；修改密码即时生效，SSH 与 HTTP 共用同一密码。

清空 DATA 分区（出厂数据重置）设备识别后、写入系统前，先擦除音箱 DATA 分区：用户数据、网络配置、时间等全部恢复出厂。适合音箱进不了系统 / 黄灯卡死 / 想彻底重置时勾选；不勾选则保留原有用户数据。
