# 小智控制米家设备

在 Web88 先上传 `mijia_mcp.sh`，再更新 `xz_watch.sh`。打开小智的「扩展」，启用「智能家居控制」，在出现的下拉框中选择 `mijia_mcp.sh` 并保存。结束当前小智对话后重新唤醒。开关默认关闭。

直接说「打开客厅灯」「关闭书房风扇」「把客厅灯亮度调到 50%」「把卧室空调调到 26 度」或「把客厅空调调到制冷模式」。设备名与房间按原厂小爱识别。使用小爱已有的登录和设备权限，无需重新输入米家账号或逐台配置设备。同名设备可以在指令中加房间名。

米家脚本通过本机原厂小爱服务提交请求，并关闭小爱的同步播报，回复由小智负责。原厂接口返回的是请求受理状态，用户可通过设备状态确认实际执行。设备能否控制、能否跨家庭解析，取决于原厂小爱的设备关联和权限。

「打开客厅窗帘」「关闭客厅灯」和「把客厅空调调到制热模式」等明确的单设备指令会通过选中的脚本直接提交。同一轮随后收到的相同 MCP 工具请求会使用已有结果，避免重复执行。

单设备指令识别完成后立即提交给原厂小爱，提交过程与小智当前一轮对话并行。同轮的工具调用复用提交结果。原厂服务受理后，小智会收到「操作成功」，按当前音色自然确认，无需再查询设备状态。语音沿用当前对话轮次，小智继续正常收听。

支持相应功能的灯具可以说「把客厅灯调成白色」「把客厅灯调成黄色」「把客厅灯切换到月光模式」「把客厅灯切换到高亮模式」。月光和高亮按米家设备的模式处理，独立于亮度百分比。

## 接入其他智能家居脚本

小智在已认证的对话 WebSocket 上提供 `self.smart_home.control`。在脚本头部前 1024 字节内单独声明 `# LX06-HOME-MCP: 1`，上传到 Web88 后即可被下拉框发现。脚本文件名应使用字母、数字、点、下划线或连字符，并以 `.sh` 结尾。

小智用 `--home-mcp-action ACTION DEVICE VALUE` 调用已选脚本。支持下列操作。开关操作会收到一个空参数。

| 操作 | 含义 | VALUE |
| --- | --- | --- |
| `on` | 打开设备 | 空 |
| `off` | 关闭设备 | 空 |
| `brightness` | 设置亮度 | 1–100 的整数 |
| `temperature` | 设置温度 | 16–30 的摄氏度整数 |
| `mode` | 设置空调模式 | `cool` 制冷、`heat` 制热、`auto` 自动、`dry` 除湿、`fan` 送风 |
| `light_color` | 设置灯的颜色 | `white` 白色、`yellow` 黄色 |
| `light_mode` | 设置灯的模式 | `moonlight` 月光、`highlight` 高亮 |

脚本应在 4 秒内退出，仅在标准输出写简短 JSON。退出码为 0 且 JSON 包含数字 `{"code":0}` 表示请求已受理。其他结果按未确认处理。脚本自己负责对应平台的权限和实际操作。小智对话退出后不再接受该会话的新调用。
