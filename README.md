# LX06 一键刷机与 Web88

## 项目介绍

这是给**小爱音箱 Pro LX06**使用的固件与脚本项目。它把音箱变成一台可以自行配置的语音终端。你可以保留官方小爱，也可以录入自己的本地唤醒词，让不同唤醒词启动小智、豆包或其他脚本。想换服务时，在音箱的 Web88 管理页改绑定或更新脚本即可。

项目由三部分组成。Windows 一键刷机工具负责通过 USB 安装固件。增强固件在音箱上提供 Web88、SSH89、本地唤醒、脚本管理和在线升级。配套脚本负责对接具体服务或执行独立任务，可以按需安装。小米、豆包、小智等服务的账号和权限由各服务提供。

例如，可以保留「小爱同学」控制智能家居，让「小智小智」进入小智对话，再配置一条小爱通道词启动后台 MCP 工单。工单处理完成后，发起任务的音箱会用官方小爱播报结果。

当前版本为 **V20261127.5-rc42**。一键刷机包、在线升级包、七个配套脚本和校验清单集中在同一个下载目录。[打开 rc42 下载文件夹](downloads/V20261127.5-rc42)

## 本地唤醒词

### 添加、录音和训练

1. 用同一局域网里的手机或电脑打开 `http://音箱IP:88`，登录 Web88。
2. 在「本地唤醒词」输入 3–4 个汉字，点击「添加」。每个词都有自己的录音、训练模型和绑定。
3. 点击该词的「配置」，选择「录音」，在提示音后自然地说一遍唤醒词。录入 **3–5 条**，再点击「训练」。若页面指出某条录音不合格，可重新录入。增补或替换录音后，可用当前样本重新训练。
4. 点击「测试」检查录音匹配。回到词条列表，启用该词，再实际说一遍，确认音箱启动了预期服务。

### 绑定、停用和删除

- **绑定脚本。** 在词条的「配置」中选择已经上传且支持唤醒的脚本。不同词可启动不同服务。选择官方小爱时，识别到本地词后会把后续对话交给官方。
- **启用或停用。** 从词条列表操作。停用后可再次启用，已有录音和配置仍可用。
- **删除。** 通过词条后的「删除」移除这个词及其录入样本和模型。删除后重新使用该词时，需要重新录入和训练。

### 官方「小爱同学」与通道词

「小爱同学（官方唤醒词）」的勾选框控制是否启用官方唤醒。旁边的链接按钮可把官方唤醒指向支持的脚本。需要用「小爱通道词」时，可让官方唤醒仍由小爱处理。先说「小爱同学」，再说脚本中保存的通道词，即可切换对话或触发任务。官方唤醒绑定、通道词和本地词绑定是三种独立的入口。

### 云端二次核对和诊断

本地唤醒首先用音箱上的声学模型比较录音。开启「云端二次核对」后，难以区分的候选录音会送到小米云端识别，并和训练记录比对。它适合处理分数接近的唤醒词，复核需要网络，也会增加这类候选的响应时间。

在「本地唤醒词」打开「高级功能」，查看「最近检测」。这里可以看到词条、检测命中、音量偏低、声学候选和云端核对状态。**检测命中和实际唤醒是不同阶段。** 排查没有响应时，结合「已提交唤醒」状态和目标脚本日志确认是否完成启动。

## 脚本功能

### 上传、配置和维护

在 Web88 的「脚本维护」点击「上传脚本」，选取脚本包里需要的 `.sh`。上传后从该脚本的「扩展」连接账户、填写设置或测试。脚本的「日志」用于排查启动、登录与会话错误。更新已安装的同名脚本时，先停止它，再覆盖上传。可用主开关管理用户脚本开机自启动和通道词调用。

扩展表单由脚本声明。例如豆包切换打断方式后，Web88 当场切换所显示的字段，保存后在后续会话使用配置。其他脚本可复用相同的输入控件、条件显示和保存机制。

### 小智 `xz_watch.sh`

在「扩展」检查绑定，按提示在小智控制台完成配对。随后可配置打断词、结束词、小爱通道词、声音增益和会话时长。通常用打断词中止当前播报，用结束词结束整个会话。

- **预留换气时间。** 默认关闭。开启后可以在一句长话中间停顿，脚本会等到所设静默时间再提交。开启时才显示「换气结束词」，默认「发送」。正文说完短停一下，再单独说「发送」，就能提前提交正文。脚本只把正文交给小智。
- **MCP 长任务。** 同一次小智对话最多跟踪 8 个由网关登记的任务。网关为每项任务提供自己的查询指令，小智在空闲时逐个取进度和结果。说再见或会话结束后，本轮停止自动查询，再次唤醒不会补播。接入方需要提供异步启动、查询与状态上报。[小智 MCP 接入方式](kws/lx06-installer/docs/xiaozhi-mcp-task-polling.md)

[小智全部字段和按钮](docs/SCRIPT_REFERENCE.md#小智)

### 豆包 `doubao_watch.sh`

打开扩展，输入自己的豆包 API Key 并点击「验证连接」。进入「对话设置」后，可设置打断方式、音色、角色要求、会话时长和输出格式，调整后点击「保存设置」。

- **打断词打断。** rc42 新安装默认模式。使用配置里的打断词中止播报，页面显示打断词输入框。
- **人声打断。** 页面显示打断音量门槛和回声保护。提高门槛后，需要更大的声音才能打断。适合按音箱音量、房间和使用距离调节。

[豆包全部字段和按钮](docs/SCRIPT_REFERENCE.md#豆包)

### ChatGPT `chatgpt_account.sh`

扩展提供「登录账户」和「完成登录」。按官网授权流程操作后，把跳转后的完整回调地址填入扩展完成授权。登录后可查看账户状态、刷新对话模型、先做文字测试，再配置语音。可以设置问候语、打断词、结束词和小爱通道词。

[ChatGPT 全部字段和按钮](docs/SCRIPT_REFERENCE.md#chatgpt)

### DeepSeek `deepseek_account.sh`

扩展支持邮箱或手机号登录。可根据账户情况使用短信验证码或密码。登录后可以检查状态、做文字测试、配置小爱通道词和语音问候。模型由 DeepSeek 官网会话匹配，可按需开启深度推理，等待时间会随任务增加。

[DeepSeek 全部字段和按钮](docs/SCRIPT_REFERENCE.md#deepseek)

### Grok `grok_account.sh`

在扩展选择「登录账户」，按提示完成官网授权。进入「对话设置」后，可查看账户状态、更新模型列表和做文字测试。可配置要启动 Grok 的小爱通道词，以及问候语、打断词和结束词。

[Grok 全部字段和按钮](docs/SCRIPT_REFERENCE.md#grok)

### 开门 `open-door.sh`

这是给对应门禁服务使用的独立动作脚本。脚本里的设备参数需按自己的授权设备配置。扩展提供手机号、密码和小爱通道词，默认通道词为「打开玻璃门」和「打开小区门」。配置完成后，用小爱通道词触发一次动作，由官方小爱播报执行结果。实际可用性取决于门禁服务和账户授权。

[开门脚本全部字段和按钮](docs/SCRIPT_REFERENCE.md#开门)

### 独立 MCP `mcp_task_watch.sh`

适合「调用一次工具，等完成后播报」的任务。扩展可填 MCP Streamable HTTP 地址、可选访问令牌、工具名、JSON 参数和最长执行时间。用配置的通道词启动后，后台任务由音箱管理，原小爱语音对话可以先结束。工具返回可播报文本后，由发起任务的那台音箱通过官方小爱播报。这个脚本在每台音箱上一次执行一个任务。[独立 MCP 接入方式](kws/lx06-installer/docs/xiaozhi-mcp-task-polling.md#独立脚本通过小爱播报)

[独立 MCP 全部字段和按钮](docs/SCRIPT_REFERENCE.md#独立-mcp)

## 固件升级

### 已有 Web88 时在线升级

1. 下载对应版本的 **`.lx06ota`**，保持原文件。登录音箱 Web88，打开顶栏「固件升级」。
2. 点击「选择升级包（.lx06ota）」。可先点「仅校验」检查格式、目标型号和文件完整性。
3. 要保留账号、配网、唤醒词和已上传脚本时，保持「清空用户数据」关闭。确认供电稳定后，点击「上传并升级」。
4. Web88 会显示上传与升级进度。固件写入备用系统并重启。等待管理页恢复，重新登录检查页面底部的固件版本，再上传对应的新脚本。

**固件与脚本各自更新。** 升级包更新音箱系统和 Web88。小智、豆包等脚本可按需单独上传。原版 rc37 用户应先更新 Web88，再安装使用新扩展条件的 rc42 小智脚本。[下载在线升级包与脚本](downloads/V20261127.5-rc42)

### 首次安装或需要 USB 刷机

1. 下载 Windows 一键刷机 ZIP，完整解压后运行 `LX06Installer.exe`。包内包含 USB 驱动、提权助手、烧录工具和固件镜像。
2. 按工具提示检测或安装驱动、连接 LX06。要使用 Web88 和 SSH89 时，选择「官方固件 + SSH」。
3. 核对 DATA 选项后开始刷写，期间保持 USB 连线和供电。刷机完成后，按正常方式配网，再用同一局域网的浏览器打开 Web88。

## 设备管理

- **设备信息。** 查看固件版本、运行时间、CPU、内存、DATA、TMP、设备温度、小爱引擎与噪音抑制状态。DATA 用于跨重启保留的用户配置和文件，TMP 用于运行时缓存。
- **日志。** 首页有「日志跟踪」，还可查看各脚本的运行日志、系统日志和崩溃记录。排查唤醒时可对照「最近检测」与脚本启动日志。
- **维护。** 顶栏提供修改密码、重启小爱和退出登录。用户程序进入安全模式时，可先查看失败原因，再使用页面提供的恢复入口。
